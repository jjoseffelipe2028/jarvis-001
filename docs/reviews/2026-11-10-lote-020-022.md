## Achados
1. **Baixo (aceito):** a "foto" do vigia de integridade fica na memória. Mudança feita com a API desligada não é vista. → v2: salvar a foto (com o OK do José) e conferir no "bom dia".
2. **Baixo (aceito):** o caminho do netstat usa `%SystemRoot%`. Quem consegue mudar o ambiente do processo da API já controla o PC. Sem `SystemRoot`, cai em `C:\Windows`.
3. **Info:** qualquer site aberto no navegador pode fazer o escritório mostrar 🚨 "pedido recusado" (o pedido é barrado, mas vira evento). É o alarme funcionando, já era assim desde o 017 em `/acoes/**`.
4. **Info:** o vigia não confere se uma **pasta do meio** (ex.: `.claude`) virou junção. Na prática o hash muda junto, a não ser que o atacante copie o arquivo idêntico.
5. **Info:** nos testes com porta aleatória (`server.port=0`), a checagem "API do Jarvis aberta para a rede" não compara com a porta real. Em produção a porta é fixa (8080).
